## Resumen

Cada run de YOLOv8 (`yolo train ...`) genera ~15 artefactos de evaluación (gráficos PNG, matrices CSV, ejemplos visuales). EN-008 consolida los relevantes para evidencia de tesis y los ubica en una carpeta consistente por run, junto con un `SUMMARY.md` autogenerado con las métricas clave.

## Script implementado

[`scripts/extract_yolo_artifacts.py`](../../../../scripts/extract_yolo_artifacts.py) — toma una carpeta `runs/detect/<run>/` y copia:

| Artefacto | Para qué sirve |
|---|---|
| `results.png` | Curvas de loss (box, cls, dfl), precision, recall y mAP por época |
| `PR_curve.png` | Curva precision-recall — visualiza el trade-off del clasificador |
| `F1_curve.png` | F1 vs confidence threshold — útil para elegir umbral de inferencia |
| `P_curve.png` | Precision vs confidence |
| `R_curve.png` | Recall vs confidence |
| `confusion_matrix.png` | Matriz de confusión absoluta |
| `confusion_matrix_normalized.png` | Misma matriz pero normalizada por filas (interpretabilidad) |
| `labels.jpg` | Distribución del dataset (clases, tamaños y ubicación de bboxes) |
| `labels_correlogram.jpg` | Correlación entre features de bboxes |
| `results.csv` | Métricas crudas por época (para re-graficar o analizar) |
| `args.yaml` | Configuración exacta del training (para reproducibilidad) |

## Resumen autogenerado

El script también escribe `SUMMARY.md` con dos secciones:

1. **Métricas de la última época** — qué reportó YOLOv8 al cierre del training.
2. **Mejor época por mAP@0.5** — qué epoch produjo el `best.pt`.

Ambas se imprimen como tablas Markdown. Ejemplo:

```markdown
## Mejor época por `mAP@0.5` (epoch 87)

| Métrica | Valor |
|---|---|
| `epoch` | 87 |
| `metrics/precision(B)` | 0.892 |
| `metrics/recall(B)` | 0.871 |
| `metrics/mAP50(B)` | 0.876 |
| `metrics/mAP50-95(B)` | 0.624 |
```

## Cómo se invoca

Automáticamente al final de `scripts/train_yolo.py` (si no se pasa `--skip-extract`).

Manualmente:

```powershell
python scripts/extract_yolo_artifacts.py `
    --run-dir ml/runs/detect/custom-v1 `
    --tag custom-v1

# Con batches (incluye train_batch*.jpg y val_batch*.jpg, varios MB)
python scripts/extract_yolo_artifacts.py `
    --run-dir ml/runs/detect/custom-v1 `
    --tag custom-v1 `
    --include-batches
```

## Notas técnicas

- **Mejor época:** el script busca columnas con `mAP50` (sin `95`) en el `results.csv` y selecciona la fila con valor máximo. Si YOLOv8 cambia los nombres de columna en versiones futuras (raro), basta con actualizar la lista `priority_keys` en el script.
- **Tags:** se recomienda usar `baseline-v0`, `custom-v1`, `custom-v2`, etc. para distinguir runs sucesivos sin que se sobrescriban en las screenshots.
