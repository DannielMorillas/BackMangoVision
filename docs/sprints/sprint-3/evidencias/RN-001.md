## Resumen

Requisito no funcional que define el **umbral mínimo de calidad** del modelo de detección antes de considerar EN-006 cerrado y pasar a EN-009 (export para producción). El número se mide sobre el **test set** (no validación), que el modelo no vio durante el training.

## Métrica

**mAP@0.5** (mean Average Precision con umbral de IoU = 0.5) calculada sobre `data/processed/test/`. YOLOv8 la reporta agregada y por clase.

```powershell

    data=data/processed/dataset.yaml `
```

## Notas técnicas

- **mAP@0.5 vs mAP@0.5-0.95:** ambos se reportan. El primero usa IoU ≥ 0.5 como umbral de "hit", el segundo promedia sobre IoU ∈ {0.5, 0.55, ..., 0.95}. El plan habla específicamente de **mAP@0.5**, así que ese es el que cuenta.
- **Tamaño de test set:** con un dataset híbrido de ~370 imágenes y split 70/15/15, el test queda con ~55 imágenes. Es suficiente para una métrica indicativa pero **el experimento cuasi-experimental del Sprint 5 (TA-001)** valida con más casos en condiciones de campo reales.
- **Comparación contra baseline público:** parte del valor académico del proyecto es mostrar que el modelo entrenado con datos propios **supera al baseline público** (Hipótesis H3 de la tesis). Eso se mide en Sprint 5, comparando `custom-v1.pt` contra `baseline-v0.pt` sobre el mismo test set.
