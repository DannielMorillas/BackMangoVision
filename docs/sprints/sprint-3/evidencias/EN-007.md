## Resumen

Mientras YOLOv8 detecta y clasifica lesiones (bounding boxes), **U-Net** segmenta a nivel de píxel para estimar el **porcentaje de área afectada** del fruto — métrica clave para clasificar la severidad como `leve`, `moderada` o `severa`.

U-Net es un track paralelo a YOLOv8 dentro del Sprint 3. No tiene los scripts CLI listos como YOLOv8 porque la arquitectura, dataset (necesita máscaras pixel-wise, no bboxes) y métricas (IoU pixel-wise) son distintos.

## Dataset

A diferencia de YOLO, U-Net consume **pares (imagen, máscara binaria)**. Las máscaras deben crearse a partir de las anotaciones de CVAT exportando en formato **"COCO Segmentation"** o **"Pascal VOC"** y luego rasterizando a PNG binario.

### Decisión de alcance

Dado que en Sprint 2 acordamos anotar 120 imágenes públicas + Casma con **bboxes** (no polígonos), técnicamente no tenemos máscaras pixel-precise. Tres opciones:

| Opción | Detalle |
|---|---|
| **A. Re-anotar en CVAT con polígonos** | Calidad alta. Costo: ~3-5x el tiempo de anotación con bbox. |
| **B. Generar máscaras pseudo desde bboxes** | El bbox rellena el rectángulo entero como máscara. Pierde detalle de forma de lesión. |
| **C. Anotar solo un subset con polígonos** (50-80 imágenes) | Mezcla A + B. U-Net entrena solo con el subset polígono. |
| **D. Diferir EN-007 a un sprint futuro** | Si el tiempo no alcanza, U-Net puede ser feature de v2 del sistema. |

**Propuesta:** discutir con el equipo en el daily-scrum del Día 1 del Sprint 3.

## Arquitectura propuesta

U-Net clásico con encoder ResNet-34 pre-entrenado (transfer learning de ImageNet). Implementación con `segmentation-models-pytorch`:

```python
import segmentation_models_pytorch as smp

model = smp.Unet(
    encoder_name="resnet34",
    encoder_weights="imagenet",
    in_channels=3,
    classes=1,           # binaria: lesion / no lesion
    activation="sigmoid",
)
```

Loss: combinación `BCEWithLogits + DiceLoss` (estándar en segmentación binaria con clases desbalanceadas).

## Integración con el sistema

El backend (Sprint 4) llamará a U-Net **después** de YOLO:

```
imagen del fruto
  └─> YOLOv8 detecta bbox de lesión (clase + confianza)
       └─> recorta la región del bbox
            └─> U-Net segmenta píxeles enfermos
                 └─> % area afectada = pixeles_lesion / pixeles_fruto
                      └─> mapeo a severidad: leve <30% | moderada 30-60% | severa >60%
```

## Notas técnicas

- **Severidad agronómica:** los umbrales 30% / 60% son convenciones. El agrónomo de ARA Export debe confirmarlos contra los estándares fitosanitarios que ellos usan (típicamente alineados con SENASA o GlobalGAP).
- **Tiempo de inferencia:** U-Net añade ~50-100ms por bbox detectada. Si una imagen tiene 5 bboxes, son 250-500ms extra sobre YOLOv8. Sigue dentro del límite de RN-002 (5 segundos end-to-end).
- **Si EN-007 se difiere:** el sistema puede arrancar en Sprint 4 sin U-Net. La severidad se reporta como "no estimada" o usando el área del bbox como aproximación grosera (cobertura del fruto detectado por la caja).
