## Resumen

Servicio de inferencia ([inference.py](../../../backend/app/services/inference.py)) diseñado con **dos modos transparentes**:

- **`real`**: si `ultralytics` está instalado **y** existe `MODEL_PATH` (`ml/models/custom-v1.pt` por defecto), carga el YOLOv8 una sola vez (singleton) y ejecuta inferencia real.
- **`stub`**: si falta cualquiera de los dos, genera detecciones **deterministas** a partir del hash SHA-256 de la imagen (misma imagen → mismo resultado).

Esto permite construir y demostrar todo el sistema end-to-end **antes** de tener el modelo entrenado (EN-006 depende de GPU + dataset anotado, ver Sprint 3).

## Cómo se activa el modelo real (sin tocar código)

1. Colocar el modelo entrenado en `ml/models/custom-v1.pt` (o ajustar `MODEL_PATH` en `.env`).
2. Instalar la dependencia: descomentar `ultralytics==8.3.0` en `requirements.txt` e `pip install`.
3. Reiniciar el backend → `mode` pasa a `real` automáticamente. Endpoints y frontend no cambian.

## Mapeo de clases

El índice de clase YOLO mapea, por orden, al catálogo MangoVision:

```
0 sano · 1 antracnosis · 2 oidio · 3 pudricion_peduncular · 4 otras_lesiones
```

`CLASS_SLUGS` en `inference.py` debe coincidir con `CLASS_NAMES` de `scripts/split_dataset.py` (verificado por test).

## Salida del servicio

Cada detección incluye: `class_slug`, `confidence`, `bbox_xyxy` (píxeles), `severity` (leve/moderado/severo por % de área) y `area_pct`. El resultado calcula además **aptitud** (`apto`/`no_apto` según `APTITUDE_AREA_THRESHOLD`, default 15%) y si el fruto está **sano**.
