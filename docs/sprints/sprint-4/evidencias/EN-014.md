## Resumen

`GET /api/metricas` ([metricas.py](../../../backend/app/api/routes/metricas.py)) devuelve métricas globales del sistema para monitoreo y para el panel de administración.

## Respuesta (`MetricasRead`)

| Campo | Significado |
|---|---|
| `total_imagenes` | Imágenes subidas |
| `total_predicciones` | Detecciones registradas |
| `por_enfermedad[]` | Conteo de detecciones por clase (slug, name, color, count) |
| `avg_inference_time_ms` | Tiempo medio de inferencia |
| `p95_inference_time_ms` | Percentil 95 del tiempo de inferencia |
| `modelo_activo` | `nombre:versión` del modelo en uso |
| `modelo_modo` | `real` o `stub` |

## Notas

- `por_enfermedad` se calcula con `GROUP BY disease_id` (agregación en SQL, no en Python).
- `p95` se calcula sobre los tiempos registrados (helper `_percentile`).
- `modelo_modo` permite a la UI advertir cuando el diagnóstico es **provisional** (stub) vs **real**.

## Criterios de aceptación

- [x] Endpoint protegido por JWT.
- [x] Devuelve conteos por enfermedad y tiempos (avg + p95).
- [x] Reporta modelo activo y modo.
- [x] Consumido por el dashboard (HU-011).
