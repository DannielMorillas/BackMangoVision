## Resumen

PostgreSQL 16 y MinIO levantados con `docker compose`. Bucket `images` creado automáticamente por un servicio one-shot `minio-init`.

## Servicios

| Servicio | Imagen | Puerto host | Puerto contenedor | Estado |
|---|---|---|---|---|
| postgres | postgres:16-alpine | 5433 | 5432 | healthy |
| minio (API S3) | minio:RELEASE.2025-01-20 | 9000 | 9000 | healthy |
| minio (consola web) | — | 9001 | 9001 | healthy |
| minio-init | mc:RELEASE.2025-01-17 | — | — | exited (one-shot) |

### Desvío del plan

El plan pedía PostgreSQL en `5432`. En esta máquina ese puerto está ocupado por `wslrelay` (probablemente un forwarding de WSL2). Para no tocar el WSL del usuario, se mapeó el contenedor a **5433 externo → 5432 interno**, y se ajustó `DATABASE_URL` en `.env` y `.env.example`. Cuando se despliegue en el servidor de ARA Export (Sprint 5) se podrá volver a 5432 estándar si el puerto está libre.

## Cómo probar

```powershell
cd c:\Users\Patrick Isla\Desktop\notion\MangoVision
docker compose up -d
docker compose ps
docker exec mangovision-postgres pg_isready -U mangovision
docker exec mangovision-minio sh -c "mc alias set local http://localhost:9000 mangovision changeme_local && mc ls local/"
```

Salida esperada:
```
mangovision-postgres   Up   (healthy)   0.0.0.0:5433->5432/tcp
mangovision-minio      Up   (healthy)   0.0.0.0:9000-9001->9000-9001/tcp
/var/run/postgresql:5432 - accepting connections
[ ... ]  0B images/
```

## Criterios verificados

- [x] PostgreSQL operativo en `localhost:5433`.
- [x] MinIO API operativa en `localhost:9000`.
- [x] Consola web de MinIO en `localhost:9001`.
- [x] Bucket `images` creado.
- [x] Healthchecks pasan en ambos servicios.
- [x] Datos persistentes en volúmenes nombrados (`postgres-data`, `minio-data`).

## Notas técnicas

- El servicio `minio-init` usa `mc mb --ignore-existing` para que sea idempotente: si el bucket ya existe, no falla.
- Las credenciales por defecto son `mangovision / changeme_local` — solo válidas para desarrollo local. Antes de desplegar en ARA Export se rotan en el `.env` real del servidor.
