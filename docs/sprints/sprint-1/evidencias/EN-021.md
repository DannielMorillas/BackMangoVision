## Resumen

Seed SQL idempotente con 5 enfermedades del catálogo oficial (sano + 4 patologías) cargado en la tabla `diseases`. Cada registro lleva `slug`, `name`, `color_hex` (para bounding boxes en el frontend) y `description` (texto agronómico).

## Catálogo cargado

| slug | name | color_hex | Notas agronómicas |
|---|---|---|---|
| `sano` | Fruto sano | `#22C55E` (verde) | Sin signos visibles de enfermedad |
| `antracnosis` | Antracnosis | `#DC2626` (rojo) | *Colletotrichum gloeosporioides* |
| `oidio` | Oídio | `#A855F7` (morado) | *Oidium mangiferae* |
| `pudricion_peduncular` | Pudrición del pedúnculo | `#F97316` (naranja) | *Lasiodiplodia theobromae* |
| `otras_lesiones` | Otras lesiones | `#FACC15` (amarillo) | Daños mecánicos, quemaduras, insectos |

## Notas técnicas

- **Trampa en Windows:** `Get-Content file.sql | docker exec -i psql` interpreta el archivo en cp1252 y corrompe los acentos antes de enviarlos. Se documenta usar `docker cp` + `psql -f` para evitarlo (ver README de seeds).
- El catálogo coincide exactamente con las 5 clases que se anotan en CVAT (HU-010) y se usan en el modelo YOLOv8 (EN-005/EN-006). Cambiar este catálogo significa reentrenar.
