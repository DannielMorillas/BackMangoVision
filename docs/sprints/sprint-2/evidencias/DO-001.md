## 1. Objetivo

Establecer un protocolo estandarizado para la captura de imágenes de frutos de mango Kent en los campos de ARA Export S.A.C. (Casma), de manera que las imágenes sean **comparables, reproducibles** y aptas para entrenar el modelo de visión computacional del sistema.

## 2. Equipamiento mínimo

| Item | Detalle |
|---|---|
| Smartphone | Cámara ≥ 12 MP, modo manual disponible |
| Fondo neutro | Cartulina blanca o gris (A3 mínimo) para algunas tomas controladas |
| Regla / referencia | Tarjeta de 5 cm o moneda visible para escala (opcional) |
| Cuaderno o tablet | Para registrar metadatos en vivo |
| Acceso al campo | Coordinado previamente con Departamento de Control Fitosanitario |
| EPP | Botas, gorra, repelente (campo abierto, sol fuerte) |

## 3. Parámetros de captura

| Parámetro | Valor objetivo | Notas |
|---|---|---|
| Distancia al fruto | 15 – 30 cm | Para que el fruto ocupe ~50–70% del frame |
| Resolución | ≥ 12 MP (4032×3024 o superior) | Verificar en Ajustes de cámara |
| Formato | JPG (no HEIC) | Cambiar el default en iPhone si aplica |
| Iluminación | Natural, evitar contraluz directo | Sombra suave preferible al sol directo |
| Enfoque | Tocar la pantalla sobre la lesión | Auto-foco fallido = borroso = descartar |
| Múltiples ángulos | 3 fotos por fruto cuando hay lesión: frente, lateral, cenital | El modelo aprende mejor con vistas variadas |
| Fruto en árbol vs cosechado | Capturar ambos contextos | Refleja el uso real del sistema |

## 4. Clases a documentar

| Clase | Mínimo recomendado | Características visuales |
|---|---|---|
| `sano` | 40 imágenes | Color uniforme, sin manchas anormales, sin deformaciones |
| `antracnosis` | 40 imágenes | Manchas oscuras circulares hundidas, tejido necrótico |
| `oidio` | 40 imágenes | Polvo blanquecino sobre flores o frutos jóvenes |
| `pudricion_peduncular` | 40 imágenes | Pudrición en la zona del pedúnculo, oscurecimiento |
| `otras_lesiones` | 40 imágenes | Daño mecánico, quemaduras de sol, picaduras |
| **Total mínimo** | **200 imágenes propias** | Combinadas con dataset público = ≥ 768 |

## 5. Procedimiento paso a paso

1. **Antes de salir al campo**
   - Cargar el smartphone al 100%.
   - Limpiar la lente.
   - Borrar fotos viejas (memoria libre).
   - Confirmar acceso con el responsable de ARA Export.

2. **En el campo, antes de fotografiar**
   - Anotar fecha, hora de inicio, zona y condiciones climáticas.
   - Identificar el lote y parcela en la planilla.

3. **Por cada fruto**
   - Fotografiar siguiendo distancia / enfoque del § 3.
   - Si hay lesión, anotar **qué clase aparenta ser** según el agrónomo presente.
   - Registrar en planilla: filename (aprox), clase tentativa, observaciones.

4. **Cada 30 minutos**
   - Pausa para verificar que las fotos quedaron bien (no borrosas, no sobreexpuestas).
   - Descartar fotos defectuosas en sitio (ahorra trabajo de filtrado después).

5. **Al cerrar la sesión**
   - Anotar hora de fin, total de fotos capturadas, incidentes.
   - Transferir las fotos al PC esa misma noche (evitar pérdida).

## 6. Estructura de archivos resultante

Las fotos se descargan a:

```
BackMangoVision/data/raw/aragroexport/images/
└── YYYY-MM-DD/                         ← una carpeta por sesión
    ├── IMG_001.jpg
    ├── IMG_002.jpg
    └── ...
```

Y el inventario en CSV:

```
BackMangoVision/data/raw/aragroexport/metadata.csv
```

con columnas:

```csv
filename,date,time,zone,lote,parcela,tentative_class,notes
IMG_001.jpg,2026-05-30,09:15,Norte,L-001,P-A,antracnosis,fruto en arbol lado este
IMG_002.jpg,2026-05-30,09:17,Norte,L-001,P-A,sano,fruto cosechado fondo blanco
```

## 8. Riesgos y mitigaciones

| Riesgo | Probabilidad | Impacto | Mitigación |
|---|---|---|---|
| Cancelación de visita por clima | Media | Alto | Tener fecha alternativa en la misma semana |
| Smartphone con batería baja | Baja | Medio | Llevar power bank y/o segundo dispositivo |
| Pocas frutas enfermas visibles | Media | Alto | Coordinar con el agrónomo qué parcela tiene mayor incidencia |
| Iluminación muy fuerte (mediodía) | Alta | Medio | Sesionar 8–11 am y 3–5 pm, evitar 11–3 pm |
| Falta del agrónomo para clasificar in-situ | Media | Medio | Capturar igual y clasificar después con el agrónomo |
